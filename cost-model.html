AWS Cognito Pricing Threshold
AWS Cognito (user authentication) is completely free for the first 50,000 monthly active users. After 50,000 MAU, each additional user costs $0.015/user/month. This is the only AWS service with a hard per-user fee — all other AWS costs (EC2, RDS, S3, VPC, etc.) are flat infrastructure rates that stay the same whether you have 1 user or 49,999. This means AWS infrastructure is essentially a fixed monthly cost until you cross 50k users, at which point Cognito begins scaling linearly.
