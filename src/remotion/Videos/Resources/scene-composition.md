# Scene Composition With Motion Graphics
When analyzing a script, do not recreate the script word-for-word on screen.
The goal is not to make animated subtitles. The goal is to translate the meaning of the script into visuals.
motion graphics should show the idea through:
•	clean UI elements 
•	minimal keywords 
•	visual metaphors 
•	icons 
•	timeline animations 
•	creator workflow diagrams 
•	floating cards 
•	before/after comparisons 
•	software-style panels 
•	cinematic overlays 
•	subtle motion accents 
Use text only when it makes the message stronger. Most scenes should rely on visual communication first and words second.
Core Rule
Do not display the sentence (unless necessary) Visualize the point.
Bad (most times):
“Creators waste hours trying to organize their editing workflow.”
On-screen text:
Creators waste hours trying to organize their editing workflow
Better:
Show a messy editing timeline, scattered files, floating warning icons, then transition into a clean workflow dashboard with a subtle glow.
Minimal words:
MESSY WORKFLOW → CLEAN SYSTEM
Visual Translation Approach
Claude Code should read each script section and ask:
“What is this line really saying visually?”
Then create a scene that represents that idea.
For example:
If the script talks about speed, show fast-moving UI cards, compressed timelines, progress bars, or time-saving counters.
If the script talks about confusion, show scattered panels, overlapping windows, blurred labels, or chaotic grid movement.
If the script talks about clarity, show everything snapping into alignment, fog fading away, clean glass panels appearing, and one clear highlighted path.
If the script talks about growth, show rising graphs, content blocks stacking upward, analytics cards improving, or a creator dashboard leveling up.
If the script talks about AI tools, show clean automation flows, prompt cards, glowing nodes, and connected systems — not cheesy robot visuals.
Text Usage
Text should be minimal and powerful.
Use:
•	1–4 word labels (complete sentence if absolutely necessary)
•	short callouts 
•	simple contrast phrases 
•	clean section titles 
•	UI-style tags 
•	button labels 
•	timeline markers 
Avoid:
•	full script sentences (only emphasis necessary ones)
•	paragraph overlays 
•	too many labels 
•	random captions 
•	text that competes with the voiceover 

Creative Freedom Rule
Claude Code should not be trapped into copying the script literally.
It should have permission to:
•	choose fitting graphics and 3d elements
•	simplify visual ideas 
•	create better metaphors 
•	build premium UI scenes 
•	use Chronixel-style layouts 
•	invent supporting visual elements 
•	improve the scene composition when needed 
But the creativity must stay inside the Chronixel style:
dark cinematic background, subtle grid, glass UI, orange gradient highlights, off-white text, premium spacing, smooth motion, no clutter.
Final Direction
The script provides the meaning.
The motion graphics provide the visual explanation.
Show the concept. Don’t repeat the words unless you list things or needed otherwise. Use your logic and add creative elements.
